# OPTION BLASTER COMMODITIES

Projet Python d’analyse des options sur matières premières, de la collecte de données de marché au reporting Excel.

## Fonctionnalités

- Consultation de données de marché Bloomberg pour les matières premières.
- Analyse des volumes, des stratégies, du ratio call/put et des expositions delta et vega.
- Visualisation de l’activité intrajournalière et des tendances avec Plotly.
- Export de synthèses et d’historiques vers Excel.
